# 💰 Expense Tracker

A modern personal finance and expense tracking web application built with **HTML, CSS and JavaScript**.

The project helps users manage their income and expenses, track their balance, analyze spending by category and month, and keep their data saved using browser **LocalStorage**.

## ✨ Features

### 💵 Income Management

* Add income with name, amount and date
* Edit existing income
* Delete income
* Automatically calculate total income

### 💸 Expense Management

* Add expenses with name, amount, category and date
* Edit existing expenses
* Delete expenses
* Clear all expenses
* Automatically calculate total expenses

### 📊 Financial Overview

* Total Income
* Total Expenses
* Current Balance
* Category-wise expense summary
* Monthly expense summary
* Expense overview and chart

### 🔎 Search & Filters

* Search transactions
* Search expenses
* Filter transactions by date
* Filter expenses by category

### 💾 Data Persistence

* Uses **LocalStorage** to save income and expense data
* Data remains available after refreshing the page

### 🎨 Modern UI

* Premium dark fintech-inspired interface
* Responsive card-based layout
* Smooth hover effects and animations
* Styled action buttons for Edit/Delete
* Clean and modern visual hierarchy

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling, responsive layout and animations
* **JavaScript** — Application logic and DOM manipulation
* **LocalStorage** — Client-side data persistence

## 🚀 How to Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or directly in your browser.
4. Start adding income and expenses.
